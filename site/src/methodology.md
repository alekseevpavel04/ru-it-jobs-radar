# Методика и ограничения

```js
import {ROLE, ROLE_GROUP, ROLE_GROUP_ORDER, SOURCE, dateLong} from "./components/labels.js";

const meta = FileAttachment("data/meta.json").json();
const life = FileAttachment("data/lifetime.json").json();
```

## Чей это срез рынка

Сайт показывает IT-вакансии из трёх открытых источников. hh.ru в выборку не входит: у него нет открытого API для такой задачи. Поэтому цифры описывают эти источники, а не весь рынок IT-вакансий России.

| Источник | Что берётся | Перекос |
|---|---|---|
| «Работа в России» (trudvsem.ru) | открытые данные портала: ежедневные снимки всего набора вакансий и ежедневная выгрузка через API | много госсектора, бюджетных организаций и регионов; IT-роли часто названы общо: «программист», «инженер» |
| Хабр Карьера | вакансии IT-компаний | вакансий меньше, чем на портале, сбор начат недавно |
| Публичные Telegram-каналы | посты с вакансиями из веб-превью каналов | уклон в ML и Python; считаются посты, а не вакансии |

```js
display(
  html`<ul>${Object.entries(meta.periods).map(
    ([source, p]) => html`<li><b>${SOURCE[source]}</b>: данные с ${dateLong(p.period_from)} по ${dateLong(p.period_to)}</li>`
  )}</ul>`
);
```

## Что публикуется

Только агрегаты: число вакансий или постов по неделям, ролям, навыкам, формату работы и группам зарплат, каждое вместе со своим знаменателем. Тексты вакансий Хабр Карьеры и постов Telegram на сайт не попадают, они хранятся только в локальном сыром слое. Персональные данные (имена контактов, телефоны, почты, ники) вычищаются ещё до записи в сырой слой. На странице о времени жизни вакансии рядом стоят два расчёта: медианы с интервалами из модели выживаемости проекта (файл указан на странице) и сроки наблюдаемых закрытий из витрины; чем они отличаются, сказано там же.

## Как считается

**Вакансия.** Одна вакансия внутри источника считается один раз: если она пришла и через API, и в снимке портала, или выложена повторно, берутся поля её последней записи. Разные источники между собой не складываются.

**Открытая, новая, закрытая.** Вакансия открыта на неделе, если была видна хотя бы в один собранный день. Новая: впервые появилась на этой неделе; в первый день сбора новых нет, там всё уже открыто, поэтому первая неделя на графике новых не показана. Закрытая: её нет в ${life.grace_days} полных снимках портала подряд, потому что портал временами прячет открытые вакансии на несколько дней (для Хабр Карьеры: нет в трёх следующих полных днях сбора). Через API вакансия не закрывается, потому что API отдаёт только изменённые записи.

**Роль.** Правило по словам заголовка (в Telegram по первой строке поста, затем по хэштегам): первая подходящая роль выигрывает. Заголовки без IT-роли (на портале в IT-раздел попадают почтальоны и операторы, на Хабр Карьере продажи и тексты) из всех цифр исключены. Правило используется, пока для «Работы в России» и Хабр Карьеры нет полей, извлечённых моделью проекта; Telegram остаётся на правилах.

**Группы ролей** на графике открытых вакансий:

```js
display(
  html`<ul>${ROLE_GROUP_ORDER.map(
    (group) =>
      html`<li><b>${group}</b>: ${Object.entries(ROLE_GROUP)
        .filter(([, g]) => g === group)
        .map(([bucket]) => ROLE[bucket])
        .join(", ")}</li>`
  )}</ul>`
);
```

**Навыки.** Словарь навыков с синонимами, поиск по заголовку, тексту и тегам навыков источника. Одна вакансия засчитывается навыку один раз.

**Telegram.** Считаются посты с вакансиями. Повтор того же текста в ту же неделю (в любом канале, без учёта ссылок, упоминаний и хэштегов) считается один раз. Пост с несколькими вакансиями не делится и идёт отдельной строкой «${ROLE.multi_post}».

## Ограничения

- Нет hh.ru, поэтому доли ролей и навыков описывают открытые источники, а не весь рынок.
- История короткая: снимки портала с ${dateLong(meta.snapshot_first_week)}, Хабр Карьера с ${dateLong(meta.periods.habr.period_from)}. Недели, за которые снимков нет, на графиках пустые, неполные недели отмечены.
- Роли и навыки определены правилами и словарём, а не разметкой. Правило ошибается на общих заголовках («инженер», «специалист»), словарь завышает навыки с широкими синонимами.
- Пост в Telegram не равен вакансии, а число постов зависит от того, какие каналы в выборке.
- Цифры пересчитываются при каждой выгрузке и могут меняться задним числом, когда догружаются пропущенные дни.

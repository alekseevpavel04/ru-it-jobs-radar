# Как сайт обновляется сам

Ежедневное обновление на GitHub Actions, его проверки против локального стека и квартальный срез навыков. Коротко в [README](../README.md).

Ежедневный workflow [`autopilot.yml`](../.github/workflows/autopilot.yml) работает на бесплатном раннере GitHub без моего стека и сервера:

1. Тот же коллектор, что собирал Telegram для локального стека, читает новые посты каналов с места, где остановился прошлый запуск. Курсоры каналов лежат в репозитории.
2. Студент Q4_K_M извлекает поля на четырёх ядрах раннера через llama.cpp. Сборка llama.cpp и веса с Hugging Face закреплены версией и sha256.
3. Недельные счётчики (неделя, канал, роль, грейд, навык) дописываются в [`aggregates/telegram/`](../aggregates/telegram/). Тексты постов остаются на раннере, в репозиторий идут только счётчики, курсоры и хэши текстов для склейки повторов недели.
4. Из счётчиков пересчитываются доли навыков, бот коммитит их, и сайт пересобирается.

Это повтор пути локального стека, и он проверен против него ([`src/radar/autopilot/checks.py`](../src/radar/autopilot/checks.py)). Раз в квартал workflow [`quarterly.yml`](../.github/workflows/quarterly.yml) пишет срез навыков ([`radar.site.quarterly`](../src/radar/site/quarterly.py)) и публикует его релизом. Срез сравнивает последние двенадцать месяцев с предыдущими двенадцатью, а не квартал с кварталом: квартал против того же квартала год назад почти ничего не показывал, во всём IT заметно сдвигался один навык из тридцати.

## Как считаются изменения долей

**Изменения долей на сайте.** Изменение доли навыка с 2022 года считается внутри каналов: участвуют каналы, где у направления были посты в оба периода, с одинаковым весом в обоих (вес Мантеля-Хензеля для разности долей). Доли направлений и грейдов по годам считаются при постоянном весе каналов, которые писали каждый год. Изменение подписано числом, если оно выходит за случайный разброс и по постам, и по каналам (бутстрэп по каналам), и проходит поправку Бенджамини-Хохберга на число навыков. Правило проверено на плацебо, где недели каждого канала за 2022 год случайно делятся на две половины и настоящих изменений нет: тест по постам срабатывает у <!--n:market/within_placebo.json:metrics.flagged_at_5pct.posts.value:.1f|pct|ru-->4,3<!--/n--> % навыков, бутстрэп у <!--n:market/within_placebo.json:metrics.flagged_at_5pct.channels.value:.1f|pct|ru-->8,6<!--/n--> % (каналов около сорока, для бутстрэпа это мало), правило по большему из двух p у <!--n:market/within_placebo.json:metrics.flagged_at_5pct.rule.value:.1f|pct|ru-->2,6<!--/n--> % при номинале 5 % ([`results/market/within_placebo.json`](../results/market/within_placebo.json)).

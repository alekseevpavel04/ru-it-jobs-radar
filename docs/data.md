## Что публикуется

**Персональные данные** вычищаются до записи в сырой слой: ФИО контактов, телефоны, почты, ники, реквизиты и адреса ИП. Только в снимках портала убрано телефонов <!--n:collect/trudvsem_snapshots.json:metrics.pii_removed_phone.value:,d|ru-->59 195 444<!--/n-->, почт <!--n:collect/trudvsem_snapshots.json:metrics.pii_removed_email.value:,d|ru-->93 889 690<!--/n-->. Всё, что публикуется (дерево git, собранный сайт, папки Hugging Face), дополнительно проверяет [`scripts/scan_pii.py`](../scripts/scan_pii.py).

**Что публикуется.** Тексты вакансий только из открытых данных портала «Работа в России», без персональных данных и со ссылкой на источник. Записи, которые портал сам перепубликовал с других сайтов, идут только полями. По Хабр Карьере, Telegram и SuperJob публикуются агрегаты и извлечённые поля, исходные тексты остаются в локальном сыром слое. Условия источников и замеры разобраны в [`docs/sources.md`](sources.md), принятые решения в [`docs/DECISIONS.md`](DECISIONS.md).

## Лицензии

Код распространяется по лицензии MIT ([`LICENSE`](../LICENSE)).

Тексты и поля портала взяты из открытых данных Роструда, при использовании нужна ссылка: «Источник: портал «Работа в России», trudvsem.ru, открытые данные Роструда». Текст типовых условий использования, на который ссылается портал, получить не удалось (подробности в [`docs/sources.md`](sources.md)). Тексты Хабр Карьеры, Telegram-каналов и SuperJob в репозиторий и на сайт не попадают, только агрегаты и извлечённые поля.

Базовая модель студента Qwen3 распространяется по лицензии Apache 2.0. YandexGPT-5-Lite-8B только размечал обучающий корпус, его веса в проект не входят и распространяются по лицензии правообладателя.

### Как устроена пагинация

`https://t.me/s/<канал>` отдаёт последние 20 постов. `?before=<id>` отдаёт до 20 постов с id меньше заданного (страница содержит `<link rel="prev" href="/s/<канал>?before=<минимальный id>">`), `?after=<id>` до 20 постов с id больше заданного. Удалённые посты оставляют пропуски в id, поэтому глубина и число постов оценены по 8 окнам по 20 постов, равномерно расставленным между первым и последним id: оценка = (последний id - первый id + 1) × (сумма постов в окнах / сумма длин окон в id). Пост: `data-post="<канал>/<id>"`, текст в `tgme_widget_message_text`, дата `<time datetime>`, просмотры, ссылка, `tgme_widget_message_forwarded_from` для пересланных. Метка `edited` есть (у 7 из 200 последних постов), даты правки нет. Часть постов показывает «Please open Telegram to view this post» (медиа, которых превью не отдаёт).

## SuperJob (api.superjob.ru)

### Условия использования

Документация https://api.superjob.ru/ : «Чтобы использовать все методы API, необходимо зарегистрировать приложение. Для каждого запроса необходимо в заголовке X-Api-App-Id передавать секретный ключ (Secret key) вашего приложения.» Ссылка «Правила работы» из подвала (https://api.superjob.ru/info/user_agreement.html) отдаёт 404, https://api.superjob.ru/register/ перенаправляет на вход в аккаунт. **Текст правил API не найден.**

### Лимиты

Текущее ограничение по частоте запросов к API: «120 запросов в минуту с одного IP-адреса. В случае превышения нормы сервер будет выдавать ошибку с кодом 503.» «Максимальное количество сущностей, выдаваемых API равно 500», `count` не больше 100. Предложение: пауза 1 с, при 503 пауза 60 с.

### Объём, поля, ПДн

Без ключа `GET /2.0/vacancies/` отдаёт 403 с текстом «Необходимо передать ключ приложения» (`tests/fixtures/superjob/vacancies_403_no_key.json`), объём не измерен. По документации у вакансии есть `date_published`, `date_pub_to`, `date_archived`, `is_archive`, фильтры `date_published_from` и `date_published_to` (инкремент) и поля контакта `contact` («Имя контактного лица»), `email`, `phone`, `fax`, в примерах ещё `contact_face`. Ключ нужен по USER_ACTIONS.

### Доступ из-за рубежа

`4fad80c3kd3f`: 403 с us1, us2, de4, nl1 (ожидаемо без ключа), de1 вернул 200, причина не выяснялась. Ответы в `tests/fixtures/superjob/checkhost_2026-10-08.json`.

### Публикация

Только агрегаты и извлечённые поля без текста (DECISIONS 2).

## Фикстуры

Заменены типы: ФИО контактного лица, телефоны (`+7 900 000-00-00` и варианты записи), почты (`@example.com`, `@example.org`), название ИП с ФИО, ИНН ИП (12 цифр), ОГРНИП и `companycode` ИП вместе с `company.url` и `vac_url`, адрес и координаты ИП, id вакансии ИП (trudvsem и Хабр) и id компании ИП (Хабр), @ники и ссылки `t.me/<ник>` людей, имена авторов пересланных постов, почты в текстах постов.

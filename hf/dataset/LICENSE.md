# Лицензия

Набор собран из нескольких источников, и условия у частей разные.

## Тексты и поля портала «Работа в России»

Столбцы `title`, `text`, `url`, `source_type`, `region`, `employer_name`, `stated_salary_from`, `stated_salary_to` конфигурации `trudvsem` взяты из открытых данных портала «Работа в России» (trudvsem.ru, Роструд). Портал описывает открытые данные как информацию, которая находится в свободном доступе в сети Интернет для использования без ограничений, и требует ссылку на trudvsem.ru при копировании. При использовании указывайте:

> Источник: портал «Работа в России», trudvsem.ru, открытые данные Роструда.

## Извлечённые поля и агрегаты

Извлечённые поля всех конфигураций (`role`, `grade`, `skills`, `salary_*`, `work_format`, `cities`, `experience_*`, `employment_type`, `lang`, `extraction_valid`) и агрегаты `habr_aggregates` это производные данные проекта ru-it-jobs-radar. Они распространяются по лицензии Creative Commons Attribution 4.0 International (CC BY 4.0): https://creativecommons.org/licenses/by/4.0/

Тексты SuperJob, Хабр Карьеры и Telegram-каналов в набор не входят.
